English Instructions

  1. Download the .apk file above.
  2. Open the file on your Android device (Requires Android 10+).
  3. Allow installation from "Unknown Sources" if prompted.
  4. Grant Wi-Fi and Storage permissions for the app to work.

Инструкции на Български

  1. Изтеглете .apk файла от бутона по-горе.
  2. Отворете файла на вашето Android устройство (Изисква Android 10+).
  3. Разрешете инсталиране от "Неизвестни източници", ако бъдете подканени.
  4. Дайте разрешения за Wi-Fi и Файлове, за да може приложението да работи.
